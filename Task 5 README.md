# Avengers Class and Object Management System

## Overview

This project demonstrates Object-Oriented Programming (OOP) in Python through an Avengers superhero management system.

An `Avenger` class is created to represent individual superheroes, with attributes such as name, age, gender, super power, and weapon.

## Objectives

- Create a Python class.
- Implement a constructor.
- Create multiple objects.
- Store object-specific attributes.
- Implement instance methods.
- Display superhero information.
- Identify the team leader.

## Technologies Used

- Python 3.x
- Classes
- Objects
- Constructors
- Instance methods
- Conditional statements

## Workflow

1. Define the `Avenger` class.
2. Create the class constructor.
3. Initialize superhero attributes.
4. Implement `get_information()`.
5. Implement `is_leader()`.
6. Create multiple superhero objects.
7. Display their information.
8. Check leadership status.

## Key Concepts

The project demonstrates:

- Classes
- Objects
- Constructors
- Attributes
- Methods
- `self`
- Conditional logic

The leadership check identifies Captain America as the team leader according to the project requirements.

## Learning Outcomes

This project provides practical experience with OOP concepts and demonstrates how classes can organize related data and functionality into reusable structures.
