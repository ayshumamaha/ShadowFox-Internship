# Student Marks File Processing System

## Overview

This project demonstrates Python file handling by reading student records from a CSV file, processing their marks, calculating total and average marks, and generating an updated CSV file.

The project introduces practical data-processing concepts using Python's CSV module and dictionaries.

## Objectives

- Read student records from a CSV file.
- Process student marks.
- Calculate total marks.
- Calculate average marks.
- Add calculated values to student records.
- Generate an updated CSV file.

## Technologies Used

- Python 3.x
- CSV module
- File handling
- Dictionaries
- Arithmetic operations

## Workflow

1. Open the input CSV file.
2. Read student records using `csv.DictReader()`.
3. Store records as dictionaries.
4. Calculate total marks.
5. Calculate average marks.
6. Add the calculated fields.
7. Create an output CSV file.
8. Write the processed records.

## Output

The generated CSV file contains the original student information together with:

- Total marks
- Average marks

## Learning Outcomes

This project demonstrates how Python can automate structured file processing and report generation while providing practical experience with CSV data and dictionaries.
