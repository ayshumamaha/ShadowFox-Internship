# Variables and Simple Interest Calculator

## Overview

This project demonstrates fundamental Python programming concepts through variable creation, data type identification, Python keyword restrictions, and arithmetic calculations.

The project also implements a Simple Interest Calculator using variables for the principal amount, rate of interest, and time period.

## Objectives

- Understand Python variables and data types.
- Demonstrate the use of the `type()` function.
- Understand restrictions associated with Python reserved keywords.
- Perform arithmetic operations using variables.
- Implement a Simple Interest calculation.
- Display clear and formatted results.

## Technologies Used

- Python 3.x
- Variables and data types
- Arithmetic operators
- `type()` function
- Print statements

## Workflow

1. Create and assign values to variables.
2. Display variable values.
3. Identify variable data types.
4. Demonstrate Python reserved-keyword restrictions.
5. Store principal, rate, and time values.
6. Calculate Simple Interest.
7. Display the result.

## Formula

Simple Interest:

`SI = (P × R × T) / 100`

where:

- `P` = Principal amount
- `R` = Rate of interest
- `T` = Time period

## Learning Outcomes

This project provides a foundation in Python variables, data types, arithmetic operations, syntax rules, and basic computational logic.
