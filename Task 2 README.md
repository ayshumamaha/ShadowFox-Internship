# BMI Category Calculator

## Overview

This project implements a Python-based BMI calculator that accepts a user's height and weight, calculates Body Mass Index, and classifies the result into predefined categories.

The project demonstrates user input, arithmetic operations, conditional statements, and decision-making in Python.

## Objectives

- Accept height and weight from the user.
- Calculate BMI using the standard formula.
- Apply conditional logic for classification.
- Display the appropriate BMI category.

## Technologies Used

- Python 3.x
- User input
- Arithmetic operators
- `if`, `elif`, and `else`
- Print statements

## Workflow

1. Enter height in meters.
2. Enter weight in kilograms.
3. Calculate BMI.
4. Compare the BMI value with category ranges.
5. Display the corresponding category.

## Formula

`BMI = Weight / Height²`

## BMI Categories

- Below 18.5 — Underweight
- 18.5–24.9 — Normal
- 25–29.9 — Overweight
- 30 and above — Obesity

## Learning Outcomes

The project demonstrates how mathematical formulas can be implemented in Python and how conditional statements can be used for automated decision-making.
