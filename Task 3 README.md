# Justice League List Management System

## Overview

This project demonstrates Python list manipulation through a simple Justice League superhero management system.

The program performs operations such as adding, removing, inserting, replacing, counting, and sorting list elements.

## Objectives

- Create and manipulate Python lists.
- Add and remove list elements.
- Insert elements at specific positions.
- Replace an existing collection.
- Count list elements.
- Sort list elements alphabetically.
- Display list updates after each operation.

## Technologies Used

- Python 3.x
- Lists
- List methods
- Indexing
- Sorting functions

## Main Operations

The project demonstrates:

- `len()`
- `extend()`
- `remove()`
- `insert()`
- `index()`
- `sort()`

## Workflow

1. Create the initial Justice League list.
2. Count the number of members.
3. Add new superheroes.
4. Move a superhero to a specific position.
5. Insert a superhero at a required location.
6. Replace the existing team.
7. Sort the final list alphabetically.
8. Display the results.

## Learning Outcomes

This project provides practical experience with Python lists, indexing, list methods, data organization, and structured manipulation of collections.
